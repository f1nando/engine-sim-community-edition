# Выбор двигателя — первый пакет

Модернизированная версия (в работе): **F2** открывает штатное Windows-меню
в позиции курсора. Выберите main.mr либо Subaru EJ25, Toyota 2JZ, GM LS,
Honda VTEC, Audi 2.3 I5, Lexus LFA V10, Ferrari F136 V8, Ferrari 412 T2 V12,
Suzuki Hayabusa I4, Harley-Davidson Shovelhead V-twin, Merlin V-1650-9 V12 (NA).
Это готовые upstream примеры, не гарантированно точные цифровые
копии серийных двигателей.

Во время меню звук останавливается, симуляция не шагает. После выбора новый
двигатель нужно завести через A / S. Enter перезагружает выбранный скрипт.
При compile error текущий двигатель сохраняется; сообщение и error_log.log
помогут найти причину. Во время записи видео смена двигателя недоступна.
Стартовая частота расчёта берётся из модели, но ограничена сверху 10000 Hz
(пользователь подтвердил хороший звук при снижении исходных 20000 Hz).
Ограничение применяется при старте, смене модели и Enter reload. N + колесо
по-прежнему позволяет настроить частоту вручную. Последующая калибровка описана
ниже. Это не гарантия realtime для любой модели; низкая частота может ухудшать точность
или устойчивость расчёта на высоких оборотах. Если звук прерывается, проверьте запас
производительности и настройку N + колесо, как при проверке baseline.

## Стартовая калибровка частоты (2026-10-12)

После загрузки/смены/Enter reload добавлена калибровка: примерно 1 секунда
прогрева и 3 секунды измерения стоимости реальных шагов физики (минимум 30
измерений). Используется 90-й процентиль времени шага и 30% бюджет для физики
(70% запас под высокие обороты, UI и аудио);
рекомендация округляется вниз по 500 Hz. Обычный диапазон — 5000–10000 Hz,
не выше частоты модели; более низкий штатный default сохраняется.
Рекомендация автоматически применяется один раз, результат показывается в строке
сообщений. N отменяет автоматический подбор, чтобы он не затирал ручную настройку.
На паузе измерения не идут; на очень низком FPS калибровка может занять дольше.

Этот этап заменяет простую установку фиксированного предела рекомендацией по
измерениям. Он не измеряет все режимы двигателя, не тестирует стабильность
численной модели и не гарантирует отсутствие underruns на высоких RPM.
Нижний предел 5000 Hz ограничивает снижение детализации, но не гарантирует,
что любой медленный CPU справится даже на этой частоте. Во время калибровки
можно завести мотор для более представительного измерения нагрузки.
Если на нижнем пределе бюджет 30% не выполняется, выводится limited CPU reserve,
а не обещание достаточного запаса. Расчёт не раскручивает двигатель до redline.

Выбор сохраняется в native/workspace/selected-engine.txt. Для возврата к ручному
скрипту выберите Current main.mr. Исходный main.mr не переписывается.

```powershell
& .\tools\native\build-baseline.ps1 -BuildName modernization
& .\tools\native\run-baseline.ps1 -BuildName modernization
```

Не запускайте две версии одновременно для проверки звука. Принятый baseline
executable сохранён в native/build/baseline/Release; новая версия собирается
в native/build/modernization/Release.

Проверки перед принятием:
- --validate-catalog из рабочей директории native/build: compile всех entry
  scripts; результат в catalog-validation.log (не проверяет runtime двигателя).
- F2: открытие, отмена без смены, переключение каждой модели, Enter reload.
- Смена работающего двигателя: нет старых графиков/звука, новый запускается.
- Перезапуск: выбранная модель восстанавливается.
- Ошибка загрузки: прежняя модель продолжает работать.

Release-сборка прошла. --validate-catalog завершился с кодом 0: все пять entry
scripts прошли compile (main.mr, Subaru, Toyota, GM, Honda). Новая GUI-версия
