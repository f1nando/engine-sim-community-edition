# Распространяемая Windows-сборка

По запросу пользователя серверное направление отложено. Цель — готовый ZIP
в GitHub Releases: распаковать целиком и запустить один EngineSim.exe.
Это не публикация закрытой Community Edition, а собственная сборка открытого
ange-yaghi/engine-sim с сохранённой атрибуцией и локальными улучшениями.

## Упаковка

Отдельная цель `PORTABLE_RELEASE` / build/portable не перезаписывает принятую
сборку build/modernization или исходный baseline. Она:

- использует только официальные Release D3DX import libraries/runtime DLL;
  не распространяет developer-only d3dx10d_43.dll;
- откладывает загрузку неиспользуемого Vulkan backend; приложение выбирает DX11,
  поэтому отсутствие Vulkan loader не должно блокировать старт;
- содержит manifest `asInvoker`, не запрашивает администраторские права;
- определяет рабочую папку относительно расположения exe, а не текущей папки
  Explorer/терминала. runtime/ содержит журналы, workspace/ — настройки;
- поставляет SDL, Microsoft CRT, DirectX Release DLL, модели, es-скрипты,
  шейдеры, используемый Silkscreen и лицензионные уведомления;
- не использует exe-упаковщики, обфускацию, сетевую дозагрузку при запуске,
  PowerShell/bat launcher, установку корневых сертификатов или изменения защиты.

Команды разработчика (пользователю готового ZIP они не нужны):

```powershell
& .\tools\native\prepare-portable.ps1
& .\tools\native\build-baseline.ps1 -BuildName portable
& .\tools\native\package-portable.ps1
```

Архив/контрольная сумма находятся в игнорируемой dist/. Готовые бинарники
публикуются как release assets, не коммитятся в исходники Git.

## Источники зависимостей и лицензии

Microsoft.DXSDK.D3DX 9.29.952.8 берётся из официального nuget.org. SHA-256 пакета
закреплён в prepare-portable.ps1, Authenticode Microsoft DLL проверяется.
Microsoft прямо разрешает application-local распространение четырёх Release DLL
из списка README пакета, но запрещает поставлять его Debug DLL. Лицензия,
NOTICE и список redistributables включаются в ZIP.

Отдельная неопределённость исторического Piranha LICENSE исследована:
в официальном upstream есть MIT LICENSE, добавленный автором commit
004fa15305655918319e825da760dc5e9fe67f60. Его неизменённый текст включён с
указанием происхождения, без самостоятельного назначения лицензии зависимости.
Остальные лицензии/уведомления также сохраняются; сторонние Microsoft DLL
не объявляются частью MIT-лицензии приложения.

## Границы безопасности

**Сертификата Code Signing в текущем профиле нет. EngineSim.exe не подписан.**
Нельзя обещать, что SmartScreen, Smart App Control, антивирусы или корпоративные
политики разрешат файл на любом ПК. GitHub Release, SHA-256 и подписи Microsoft
на зависимостях не заменяют подпись нашего издателя и не гарантируют безопасность.

При блокировке не просить отключать защиту, менять ExecutionPolicy, обходить
политику, удалять Zone.Identifier или добавлять антивирусные исключения.
Решение — корректная подпись доверенным сертификатом/службой подписи и
разрешение администратора в управляемой среде; сертификат не приобретается
и никакие сторонние условия оплаты не принимаются без отдельного согласования.

Первый выпуск маркируется предварительным. До заявления широкой совместимости
нужен запуск на чистом Windows-ПК/VM с меткой загрузки из интернета. Локальная
проверка отдельно распакованного ZIP не заменяет такой тест и проверку звука.

## Выпуск 1.0.0-lab.1 — результаты

- Отдельная portable Release-сборка успешна, принятый exe modernization не заменён.
- Создан ZIP размером 7 126 544 байта с одним запускаемым EngineSim.exe.
- В импортируемых DLL нет debug D3DX; Vulkan находится только в delay-load.
- Проверены SHA-256 всего распакованного содержимого, запуск из другой рабочей
  папки с пробелами, 12/12 скриптов каталога, 39/39 integration условий и обычное
  отвечающее GUI-окно с нормальным завершением.

  калибровки был уточнён: пограничное округление IEEE double вниз до 7000 вместо
  теоретических 7500 остаётся консервативным и допустимым; добавлена отдельная
  проверка этого случая. Алгоритм калибровки/физика ради теста не менялись.
- Подпись нашего exe: NotSigned. Чистая Windows VM, запуск с меткой загрузки
  из интернета, аппаратные клики и качество звука этим прогоном не подтверждены.
- Исходники native опубликованы в f1nando/engine-sim, commit ad1e40f.
