ENGINE SIM LAB 1.0.0-lab.1 - Windows 10/11 x64
Неофициальная модернизация открытого Engine Simulator от Ange Yaghi.
Это не официальный выпуск закрытой Community Edition.

ЗАПУСК
1. Распакуйте ВЕСЬ ZIP в обычную доступную для записи папку.
2. Запустите EngineSim.exe. Сборка программы, PowerShell и администратор не нужны.
Не запускайте exe прямо из окна просмотра ZIP и не переносите его отдельно от папки.

УПРАВЛЕНИЕ
F2 - выбор двигателя; Enter - перезагрузка.
A - зажигание; удерживать S - стартер.
Q/W/E/R - положения газа; Space + колесо - точная настройка газа.
Shift - выжать сцепление; стрелки вверх/вниз - передача.
D - динамометр; H - удержание RPM; G + колесо - настройка удерживаемых RPM.
N + колесо - частота физики; F - полный экран; Escape - выход.

ГРАФИКИ
Клик по подключённому стрелочному прибору добавляет его линию снизу.
Повторный клик убирает только её. Выбранный прибор отмечен цветной рамкой.
Колесо над нижней областью листает страницы шкал (линии остаются видимыми).
Наведите мышь на график для сравнения значений в один момент времени.
Момент и мощность требуют включённого dyno; без измерения показывается N/A.
Остальные исходные мини-графики пока сохраняют прежние отдельные оси.

БЕЗОПАСНОСТЬ
Приложение НЕ подписано сертификатом издателя. Даже исправный и проверенный
ZIP может вызвать предупреждение SmartScreen или блокировку политикой Windows.
Подписи Microsoft на DLL НЕ являются подписью нашего exe.
Не отключайте Defender/SmartScreen/Smart App Control и не добавляйте исключения.
Если запуск заблокирован, сообщите об ошибке издателю/администратору.
Никаких загрузок файлов при запуске, автообновления или сетевого сервера здесь нет.
SHA256SUMS.txt и страница GitHub Release позволяют проверить целостность архива;
контрольная сумма не заменяет подпись издателя или проверку безопасности.

ОГРАНИЧЕНИЯ
Симулятор - учебная визуализация, а не валидированный инженерный инструмент.
Не использовать показания как точные паспортные данные или для настройки
реального двигателя без независимой проверки. Скорость зависит от CPU и модели.
Начальная калибровка частоты (~4 секунды) не гарантирует realtime на любых RPM.
